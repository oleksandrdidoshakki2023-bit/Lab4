# 🧠 Second Brain

Локальний персональний Second Brain для студента — вебзастосунок для створення,
редагування та перегляду Markdown-нотаток, організованих за методологією PARA.

## Опис проєкту

Second Brain допомагає організувати навчальні матеріали, конспекти та ідеї
у структурованій системі з підтримкою вікі-посилань між нотатками.

**Можливості:**
- Створення та редагування Markdown-нотаток через вебінтерфейс
- Організація за категоріями PARA: Inbox, Projects, Areas, Resources, Archives
- Пошук (регістронезалежний) по назві, тегах і тілу нотатки
- Фільтрація за категорією та тегом (можна комбінувати з пошуком)
- Вікі-посилання `[[Назва нотатки]]` з автоматичним резолвінгом
- Виявлення битих посилань (червоний текст)
- Зворотні посилання (backlinks)
- Рендеринг Markdown у HTML

## Вимоги

- Python 3.11+
- pip

## Встановлення і запуск

```bash
# Клонувати репозиторій
cd Lab4

# Створити віртуальне середовище (рекомендовано)
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# Встановити залежності
pip install -r requirements.txt

# Запустити сервер
python src/app.py
```

Відкрити у браузері: [http://127.0.0.1:5000](http://127.0.0.1:5000)

## Запуск тестів

```bash
python -m pytest -v
```

## Архітектура

Детальний опис — у [docs/architecture.md](docs/architecture.md).

Коротко:
- **`src/notes.py`** — модуль даних, не залежить від Flask
- **`src/app.py`** — Flask-маршрути, рендеринг шаблонів
- Нотатки зберігаються як `.md`-файли з YAML frontmatter
- Нотатки читаються з диска при кожному запиті (без кешу)
- Сервер слухає лише `127.0.0.1`

## Модель нотатки

```yaml
---
title: "Назва"
created: "2026-10-23T11:00:00+03:00"
updated: "2026-10-23T11:00:00+03:00"
type: note        # note | moc
status: active    # inbox | active | archived
tags: [тег1, тег2]
source: "джерело"
---

Тіло нотатки у Markdown.
Посилання: [[Інша нотатка]]
```

Категорія визначається підпапкою (`notes/Inbox/`, `notes/Resources/` тощо).

## Обмеження

- Один користувач, без авторизації
- Видалення нотаток через інтерфейс відсутнє (захист від втрати даних)
- Повнотекстовий індекс не реалізований (простий пошук підрядка)
- Переміщення нотаток між категоріями — лише через файлову систему
- Назви файлів = назви нотаток + `.md`

## Політика приватності

- 🔒 Усі дані зберігаються **лише локально** на комп'ютері користувача
- 🚫 Жодні дані **не передаються** зовнішнім сервісам або API
- 🔐 Сервер слухає лише `127.0.0.1` — недоступний з мережі
- ⚠️ **Не комітьте** у репозиторій персональні дані, паролі та секрети
