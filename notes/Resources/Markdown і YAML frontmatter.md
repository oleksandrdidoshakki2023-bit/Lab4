# Markdown і YAML frontmatter

Markdown — це легка мова розмітки, створена Джоном Грубером. Вона дозволяє писати форматований текст у простому текстовому файлі. Markdown широко використовується в документації, README-файлах і системах нотаток.

Основні елементи синтаксису: заголовки (`#`), жирний (`**текст**`), курсив (`*текст*`), списки (`-` або `1.`), посилання (`[текст](url)`), код (зворотні лапки), блоки коду (три зворотні лапки).

**YAML frontmatter** — це блок метаданих на початку Markdown-файлу, обгорнутий у `---`. У ньому зберігаються структуровані дані: назва, дата, теги, статус тощо.

Бібліотека `python-frontmatter` дозволяє зручно парсити такі файли в Python: вона розділяє метадані (як словник) і тіло нотатки (як рядок). Бібліотека `markdown` конвертує Markdown-текст у HTML для відображення у браузері.

Поєднання Markdown і YAML frontmatter є стандартом для систем персональних знань, таких як Obsidian, Jekyll та інші.
