# Модель PARA

PARA — це система організації цифрової інформації, запропонована Тіаго Форте. Абревіатура розшифровується як Projects, Areas, Resources, Archives.

**Projects (Проєкти)** — активні завдання з конкретним дедлайном і результатом. Наприклад, «Написати лабораторну роботу №4». Проєкт завершується, коли результат досягнуто.

**Areas (Області)** — сфери відповідальності без конкретного дедлайну. Наприклад, «Навчання», «Здоровʼя», «Фінанси». Області потребують постійної уваги.

**Resources (Ресурси)** — довідкові матеріали, які можуть стати у пригоді. Конспекти лекцій, корисні статті, шаблони. Ресурси не потребують дій, лише збереження.

**Archives (Архів)** — неактивні елементи з трьох попередніх категорій. Завершені проєкти, неактуальні ресурси. Архів зберігає історію, але не відволікає від поточних справ.

Перевага PARA — простота: будь-яку одиницю інформації можна віднести лише до однієї з чотирьох категорій. Також додається категорія Inbox для нових нотаток, які ще не класифіковано.
