# Ідея про Git worktree

Git worktree дозволяє мати кілька робочих директорій, прив'язаних до одного репозиторію. Кожна директорія може бути на окремій гілці, і між ними можна перемикатися без stash чи коміту.

Це корисно, коли потрібно одночасно працювати над кількома фічами або тримати стабільну версію в одній папці, а експериментальну — в іншій.

Команда `git worktree add ../feature-branch feature-branch` створює нову робочу директорію. Команда `git worktree list` показує всі активні worktree.

Потенційно це може спростити роботу з лабораторними: тримати кожну лабораторну в окремому worktree, не перемикаючи гілки в основній директорії.

Треба розібратися, як це працює з IDE та чи є обмеження на Windows.
