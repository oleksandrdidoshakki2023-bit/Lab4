# Проєктне рішення: хмарна версія Second Brain

## Огляд

Цей документ описує **проєктне рішення** для розгортання Second Brain у хмарі.
Фактичне розгортання **не виконується** — лише архітектурний опис.

## Компоненти

### 1. Статичний інтерфейс
- HTML/CSS/JS розгортається на CDN (AWS CloudFront + S3, або Firebase Hosting)
- Взаємодія з бекендом через REST API

### 2. Бекенд (API)
- Flask-застосунок у контейнері (Google Cloud Run / AWS ECS / Azure Container Apps)
- Або серверлес: AWS Lambda + API Gateway
- Автентифікація через JWT або OAuth 2.0

### 3. Сховище нотаток
- **Варіант А**: Об'єктне сховище (S3 / GCS) для `.md` файлів — зберігає формат локальної версії
- **Варіант Б**: Реляційна БД (PostgreSQL) — метадані в таблицях, тіло нотатки в текстовому полі
- **Варіант В**: NoSQL (Firestore / DynamoDB) — документ-орієнтована модель

### 4. Автентифікація
- OAuth 2.0 (Google, GitHub) або email + пароль
- JWT-токени для API-запитів
- Рольова модель: власник нотаток бачить лише свої

### 5. Резервне копіювання
- Автоматичні бекапи БД (щоденні, retention 30 днів)
- Версіонування об'єктів у S3/GCS
- Експорт нотаток у `.md` (ZIP-архів) для локального бекапу

## Порівняння локальної та хмарної архітектур

| Критерій | Локальна версія | Хмарна версія |
|---|---|---|
| **Приватність** | ✅ Максимальна: дані лише на ПК | ⚠️ Дані на серверах провайдера; потрібне шифрування |
| **Доступність** | ⚠️ Лише з одного ПК | ✅ Доступ з будь-якого пристрою 24/7 |
| **Вартість** | ✅ Безкоштовно | ⚠️ Оплата хостингу, БД, трафіку (від ~\$5/міс) |
| **Vendor lock-in** | ✅ Немає: файли `.md` — відкритий формат | ⚠️ Залежність від хмарного провайдера |
| **Складність експлуатації** | ✅ Мінімальна: `python app.py` | ⚠️ CI/CD, моніторинг, оновлення, бекапи |
| **Масштабування** | ❌ Один користувач | ✅ Багато користувачів, автомасштабування |
| **Офлайн-режим** | ✅ Повна робота без інтернету | ❌ Потрібен інтернет (або PWA + sync) |
| **Швидкість** | ✅ Миттєвий доступ до файлів | ⚠️ Мережева затримка |
| **Резервування** | ⚠️ Ручне (Git) | ✅ Автоматичне |
| **Безпека** | ✅ Фізичний контроль | ⚠️ Потрібна автентифікація, HTTPS, WAF |

## Висновок

Для навчального проєкту одного студента **локальна версія є оптимальною**:
максимальна приватність, нульова вартість, простота експлуатації.

Хмарна версія доцільна, якщо потрібен:
- Доступ з кількох пристроїв
- Спільна робота кількох користувачів
- Автоматичне резервне копіювання
- Публічний доступ до окремих нотаток
